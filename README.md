# TanKa · ทันกะ

จัดรถรับส่งพนักงานตามตารางกะ — https://tanka-app.github.io

- `index.html` — ตัวแอปทั้งหมด (หน้าเลือก คนขับ/เจ้าของ, ตารางรายวัน, เส้นทาง, ใบขอรถ, จับคู่จอในรถ)
- `sw.js` — เก็บตัวแอปไว้ในเครื่อง ให้เปิดได้ตอนไม่มีเน็ต

ข้อมูลทั้งหมดอยู่ใน Supabase (ควบคุมสิทธิ์ด้วย Row Level Security) — repo นี้ไม่มีข้อมูลพนักงาน
**ห้ามอัปไฟล์สำรองข้อมูล (.json) ตารางกะ หรือ secret key ขึ้น repo นี้**
